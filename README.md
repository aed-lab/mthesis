# 修士論文master
修士論文のマスター


マスターファイルは G31xxyyy_Main.tex です．
x,yのところに自分の学籍番号を入れます．

latexのソースファイルは srcの中に保存します．
画像ファイルは fig の中に入れます

論文リストは bib/ に置きます．サンプルは BibTeX.bib です．

2024/10から Devcontainerに対応しているので、 Vscodeと docker がインストールされていれば環境は簡単に構築することができます。

2026/08から Github Codespacesに対応しているので、githubの上から
codespacesを開くことで、手元に何もインストールすることなくオンラインで編集、PDFの生成が可能です。
ただし、Codespacesは学生の無料プランの場合１ヶ月あたり180CPU時間、
最低限のスペックが2コアなので 90時間しか使うことができません。
それ以上悩みたい場合には手元で vscode + docker の環境を整備します。
